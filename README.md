# Клубок

Помощник для вязания спицами и крючком. Android, Flutter + SQLite, всё хранится на телефоне.

## Что умеет

**Счётчик**
- большой клубок на весь экран: нажала — плюс один ряд;
- кнопки громкости тоже считают (вверх +1, вниз −1), экран при этом не гаснет;
- несколько счётчиков на проект: ряды, рукав, прибавки;
- цель («связать 120 рядов») с ниткой-прогрессом вокруг клубка;
- раппорт («узор повторяется каждые 8 рядов»): показывает ряд внутри раппорта и номер повтора, в конце раппорта — отклик вибрацией.

**Проекты**
- фото, спицы или крючок и их размер, плотность, схема, заметки;
- статус: в работе, на паузе, в планах, готово;
- какая пряжа из запасов идёт на проект и сколько мотков.

**Пряжа**
- марка, название, цвет, состав, вес и длина мотка, партия, фото;
- сколько мотков дома (можно дробно) и сколько это метров;
- поиск по запасам.

## Как собрать APK

Так же, как Bierboek и Молитвослов, — через GitHub Actions:

1. Создать репозиторий на GitHub и залить в него всё содержимое этой папки (вместе с `.github`).
2. Сборка стартует сама при каждом push в `main`; запустить вручную можно на вкладке **Actions → Собрать APK → Run workflow**.
3. Готовый файл `klubok.apk` лежит в артефактах запуска (`klubok-apk`), а после сборки ветки `main` ещё и по постоянной ссылке `releases/latest/download/klubok.apk` — её удобно открыть прямо с телефона.

APK собирается под arm64 — это все телефоны последних лет. Для совсем старого телефона убери `--target-platform android-arm64` в `.github/workflows/build.yml`.

Собрать на своём компьютере, если стоит Flutter:

```
flutter create --platforms=android --org nl.mikem --project-name klubok .
flutter pub get
flutter build apk --release
```

## Про ключ подписи

В `ci/debug.keystore` лежит постоянный отладочный ключ (пароль стандартный, `android`). Он нужен только затем, чтобы каждая сборка была подписана одинаково: тогда обновление ставится поверх старой версии и записи не теряются. Для личного приложения этого достаточно; для публикации в магазине нужен свой закрытый ключ.

## Где что лежит

| Файл | Что в нём |
| --- | --- |
| `lib/main.dart` | запуск, три вкладки, нижняя панель-резинка |
| `lib/theme.dart` | цвета «шерстяной» палитры, шрифты |
| `lib/knit.dart` | всё вязаное: фактура глади, заплатки со строчкой, клубок, пуговицы |
| `lib/store.dart` | база SQLite и все операции с данными |
| `lib/models.dart` | проект, счётчик, пряжа |
| `lib/device.dart` + `android/.../MainActivity.kt` | кнопки громкости и «экран не гаснет» |
| `lib/photos.dart` | фото с камеры и из галереи |
| `lib/screens/` | экраны: счётчик, проекты, пряжа |

Название на телефоне меняется в `android/app/src/main/AndroidManifest.xml` (`android:label`).

## Шрифты

Pacifico и Balsamiq Sans — открытая лицензия SIL OFL, тексты лицензий лежат рядом со шрифтами в `assets/fonts/`.
